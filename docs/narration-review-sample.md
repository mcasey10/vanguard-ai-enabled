# Feature 1 narration — review sample set

One real example per §12 coverage category (`CLAUDE.md`), generated by actually running the narration pipeline against real dataset values (`dev/src/data/sample-dataset.json`) — no invented numbers, no hand-written prose. This file is for a human review pass. It is not consumed by any code.

## Important: this is the deterministic fallback, not live model output

No `ANTHROPIC_API_KEY` is configured in the environment this was generated in, so every sample below is `buildDeterministicFallback()`'s output — the same plain, factual text a real user sees if the live Anthropic call fails (`CLAUDE.md` §7, `DECISIONS.md` D038 rule 5). It is genuinely computed from real structured figures, not fabricated, but it is **not** the AI's actual voice — the live model, given the identical structured input, is free to write richer, more varied prose within the same figure constraints. Regenerate this file with a real API key configured to review actual model output instead.

**Two real gaps in the deterministic fallback specifically, found while generating this set — worth a look before relying on it as a permanent fallback:**
- **Categories 6 and 7 render identical text.** `buildDeterministicFallback()` never reads `input.allocation_impact` at all — it only narrates per-fund gain/loss and net tax. The two allocation scenarios differ only in `allocation_impact` (before/after/target), so the fallback can't tell them apart. The live model *would* distinguish them (it receives `allocation_impact` in the prompt payload), but the non-AI fallback path currently can't.
- **Category 4 (ST-LT crossing) doesn't call out the ST/LT split.** The fallback sums `st_gain_loss + lt_gain_loss` into one "realizing a gain of $X" figure rather than describing the short-term and long-term portions separately, even though both are present and non-zero in the input. Not wrong (the total is correct), just less specific than the underlying data supports.

Neither is a live-model bug — both are gaps in the plain-text fallback builder (`buildDeterministicFallback()` in `dev/src/utils/narrationShared.ts`). Flagged, not fixed, per this session's scope (see `DECISIONS.md`).

## 11. Market-context exclusion-check mechanism

- **Touchpoint:** Fund Selection rationale
- **Segment tone:** A
- **Source data:** VFITX, two different lots in the same fund — one excluded, one not

**Excluded pairing (VFITX / `IRA-VFITX-06`):**
> Selling $3,255.00 of Vanguard Intermediate-Term Treasury Index Fund Admiral Shares (domestic bonds) via FIFO, realizing a loss of $15.00. Traditional IRA withdrawals are taxed as ordinary income regardless of this gain/loss figure.

No market-context sentence — `isMarketContextExcluded('VFITX', ['IRA-VFITX-06'], market_context_exclusions)` returns `true`. Reason on file: *"Real trailing-12-month return (+5.48%) conflicts in sign with this lot's fictional unrealized loss (-$15.00). Adjusting the lot's cost_basis_per_share to resolve the conflict cascades into unrealized_st_gain_loss, total_unrealized_gain_loss, and total_cost_basis at the holding level, three UI pages that render those fields (FundSelectionManual2, FundSelectionManualLot, OrderConfirmation), and computed_aggregates' self-consistency checks... Rather than adjust either the verified real figure or the fictional lot, the market-context narration sentence is suppressed for this specific fund/lot pairing."*

**Non-excluded pairing, same fund, different lot (VFITX / `IRA-VFITX-02`):**
> Selling $27,125.00 of Vanguard Intermediate-Term Treasury Index Fund Admiral Shares (domestic bonds) via FIFO, realizing a gain of $625.00. Traditional IRA withdrawals are taxed as ordinary income regardless of this gain/loss figure. Vanguard Intermediate-Term Treasury Index Fund Admiral Shares has gained 5.48% over the trailing 12 months.

Market-context sentence present — `isMarketContextExcluded('VFITX', ['IRA-VFITX-02'], ...)` returns `false`; `market_context_return_pct` resolves to the real, sourced `5.48`. This confirms the check is scoped to the specific (fund, lot) pairing, not the fund as a whole.
